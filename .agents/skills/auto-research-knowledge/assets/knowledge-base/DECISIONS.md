# 协作决策

本文件用于记录当前项目的协作约定和研究决策，初始化时补充实际日期与依据。

## 默认工作方式

- 日常研究讨论、结果解释和方案建议自动检索已有知识库，结合模型已有知识、实际项目文件及必要的网页查证，无需每次手动调用 skill。
- 用户明确要求后开展系统性文献搜集、全文精读、批量归档或计算复现；普通问答不自动转成已核验的文献笔记。
- 以一个研究问题为单位整理证据、方法及研究建议，文献篇数按需要决定。
- 可自主运行轻量本机复现；预计长时计算或大量下载时先说明具体资源需求。
- 知识库归属于当前项目，其他项目按使用者明确选择分别初始化。
- 普通查库、文件保存、Git 提交和 GitHub 推送按各自任务范围执行。
- 关键研究判断注明实际使用的知识条目、项目材料或网页出处，区分资料结果与综合推理。
- 多对话各编辑独立草稿，正式归档通过 skill 的 knowledge_write.py 做锁定与版本检查；冲突保留双方内容，读取最新版本后逐段合并。使用Git时忽略运行记录、备份与锁。
