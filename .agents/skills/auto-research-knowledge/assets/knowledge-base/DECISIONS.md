# 协作决策

本文件用于记录当前项目的协作约定和研究决策，初始化时补充实际日期与依据。

## 默认工作方式

- 日常研究讨论检索已有知识库；用户明确要求后开展新文献检索、精读或复现。
- 以一个研究问题为单位整理证据、方法及研究建议，文献篇数按需要决定。
- 可自主运行轻量本机复现；预计长时计算或大量下载时先说明具体资源需求。
- 知识库归属于当前项目，其他项目按使用者明确选择分别初始化。
- 普通查库、文件保存、Git 提交和 GitHub 推送按各自任务范围执行。
